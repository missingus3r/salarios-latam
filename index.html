API libre

Sin auth, sin rate limit. Los datos viven como JSON estático en GitHub Pages — pegale fetch desde donde quieras.

Endpoints

  • GET /data/salaries.json — registros actuales (192)
  • GET /data/history.json — series temporales 2020-2026
  • GET /data/meta.json — versión, fuentes, contadores

Base: https://missingus3r.github.io/salarios-latam/

Ejemplo curl

curl -s https://missingus3r.github.io/salarios-latam/data/salaries.json \
  | jq '.[] | select(.pais == "Uruguay" and .rol == "Desarrollador Backend")'

JavaScript

const data = await fetch('https://missingus3r.github.io/salarios-latam/data/salaries.json').then(r => r.json());
const uy = data.filter(r => r.pais === 'Uruguay');

Python

import requests
data = requests.get('https://missingus3r.github.io/salarios-latam/data/salaries.json').json()
uy = [r for r in data if r['pais'] == 'Uruguay']
